## Description

The Bellwether is a minimalist two-tone 11ty starter kit made with long-form content in mind.

## Prerequisites

- [Node.js](https://nodejs.org) version 18 or later
- [11ty](https://www.11ty.dev) version 3.1.6 or later

## Installation

1. Download and extract the latest release or open a terminal and run:

```bash
git clone https://github.com/meganrenae21/the-bellwether.git
```

2. While in the root directory, install the required dependencies by running:

```bash
npm install
```

3. Build the site by running:

```bash
npm run dev
```

This will create a folder `_site` which will contain your build files, and it will open a local server at port 8080. View the site at `https://localhost:8080`. To close the server, press `Ctrl+C` in the terminal.

You can rebuild the site at any time by running `npm run dev` (which will open a dev server) or `npm run build`.
